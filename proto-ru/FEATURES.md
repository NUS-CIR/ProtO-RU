# Features

The current implementation of ProtO-RU aligns with the requirements of a Category A O-RAN Radio Unit supporting split 7.2. 

Support for Category B features is planned for future releases.

## Current Features

- Support for various SDRs (e.g., USRP B210)
- TDD and FDD support
- BFP compression and decompression
- 15kHz and 30kHz SCS support
- Short PRACH preamble (limited to format B4)
- Per-slot C-plane packet handling
- MIMO support (tested up to 2x2 on the B210)
- Realtime KPI monitoring

## Coming Soon

- DPDK support
